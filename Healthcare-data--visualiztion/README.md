# Task 3 - Healthcare Data Visualization Dashboard

## Project Overview
This project is Task-3 of CodeAlpha Data Analytics Internship.
Objective is to perform exploratory data analysis and create interactive visualizations to extract insights from healthcare dataset.

##  Visualizations Created
1. Billing Analysis by Medical Condition - Cost variation across diseases
2. Admission Type Analysis - Emergency vs Elective vs Urgent
3. Age Distribution - Which age group needs more care
4. Yearly Trend - Admission trends over years
5. Insurance Provider Analysis - Coverage by provider
6. Medical Test Results - Normal / Abnormal / Inconclusive ratio

##  Key Insights
- Senior patients (50-70 yrs) have highest hospital visits and billing.
- Emergency admissions dominate - 55% of total cases.
- Diabetes & Hypertension are top medical conditions.
- Medicare and private insurance cover 70% patients.
- 30% medical tests show Abnormal results requiring follow-up.
- Billing cost increases with chronic conditions and length of stay.
